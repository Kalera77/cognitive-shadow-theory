### 2.3 Параметризация Теоремы 3.9 через ε (сентябрь 2026)

В рамках обновления формального ядра Теорема 3.9 и Теорема 4 были параметризованы через операционный параметр чувствительности ε ∈ (0, 1/2). Ранее использовался фиксированный порог 0.51.

**Изменения:**

| Параметр | Было | Стало |
|---|---|---|
| Порог предсказуемости | Фиксированный: 0.51 | Параметризованный: 1/2 + ε |
| Формула прогноза | T = ⌈max(0, (H_min/0.51 − H₀)/δ_min(M))⌉ | T(ε) = ⌈max(0, (H_min/(1/2+ε) − H₀)/δ_min(M))⌉ |
| Операционное значение | — | ε = 0.01 (порог 1/2 + ε = 0.51) |
| Обоснование | Точка бифуркации | Оптимум по критерию Юдена (Youden's J = 0.2069) |

**Доказанные свойства:**

1. `parasitism_limit_param`: для любого ε ∈ (0, 1/2) существует время T(ε), после которого предсказуемость ≤ 1/2 + ε.
2. `predictability_horizon_param`: при достижении энтропией порога H_min/(1/2+ε) предсказуемость не превышает 1/2 + ε.
3. `parasitism_limit_051`: совместимость со старым порогом 0.51 сохранена как королларий.
4. Монотонность по ε: меньшее ε → более строгий порог.

**Модули, затронутые параметризацией:**
- `GlobalParameters.v` — добавлены `epsilon_op`, `predictability_threshold`, `entropy_target`
- `ParasitismTheorem.v` — параметризованная теорема и королларии
- `AlgorithmicEntropy.v` — параметризованный когнитивный горизонт


### 2.4 Исправленная аксиоматика Теоремы 10 (сентябрь 2026)

Исходная аксиома `A10_auc_bounds` была взрывной: константный классификатор `fun _ => true` имеет AUC = 0.5, что нарушало строгое неравенство `0.5 < AUC`. Аксиома была разделена на три корректные:

| Аксиома | Формулировка | Статус |
|---|---|---|
| `A10_auc_exists` | ∃ информативный классификатор: 0.5 < AUC(c, true_label) < 1 | ✅ Доказана |
| `A10_auc_not_perfect` | ∀ классификатор: AUC(c, true_label) < 1 | ✅ Доказана |
| `A10_auc_above_chance` | ∀ согласованный классификатор: AUC(c, true_label) ≥ 0.5 | ✅ Доказана |

**Эмпирическое подтверждение:**
- `A10_auc_exists` подтверждено: AUC = 0.947 для CLIS vs healthy
- `A10_auc_not_perfect` подтверждено: максимальный AUC = 0.947 < 1
- `A10_auc_above_chance` подтверждено: контрольные задачи дают AUC ≈ 0.5

Теорема `SignatureObservability` переформулирована под исправленную аксиоматику и успешно доказана.
