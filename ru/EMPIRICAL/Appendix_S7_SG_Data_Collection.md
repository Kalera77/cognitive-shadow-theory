## 1. Обзор

Для эмпирической проверки предсказаний микрооснований SDT необходим единый датасет, объединяющий три типа прокси для семантического разрыва $SG(t)$:

| Прокси | Источник | Период | Формула |
|--------|----------|--------|---------|
| **Индекс доверия** | Edelman Trust Barometer | 2012–2025 | $SG_{trust} = 1 - TrustIndex/100$ |
| **Теневая экономика** | IMF Working Paper WP/18/17 | 1991–2015 | $SG_{shadow} = ShadowEconomy/100$ |
| **Эмиграция** | Fragile States Index E3 | 2006–2024 | $SG_{emigration} = E3/10$ |

## 5. Объединение в единый датасет

### 5.1. Формат

**Ключевые поля:** `country` (ISO-3), `year`

| country | year | trust_index | shadow_economy | E3 | SG_trust | SG_shadow | SG_emigration | SG_total |
|---------|------|-------------|----------------|----|----------|-----------|---------------|----------|
| USA | 2015 | 52 | 8.9 | 2.1 | 0.48 | 0.089 | 0.21 | 0.26 |

### 5.2. Формула SG_total

$$SG(t) = w_1 \cdot SG_{trust} + w_2 \cdot SG_{shadow} + w_3 \cdot SG_{emigration}$$

**Калибровка весов:**
- Приоритет — институциональное доверие: `w₁ = 0.5, w₂ = 0.3, w₃ = 0.2`
- Исторические кейсы без Edelman: `w₁ = 0, w₂ = 0.5, w₃ = 0.5`

### 5.3. Проблема временных окон

| Источник | Период |
|----------|--------|
| Edelman | 2012–2025 |
| IMF Shadow | 1991–2015 |
| FSI E3 | 2006–2024 |

**Пересечение:** 2012–2015 (4 года)

**Решение для исторической регрессии:**
- Кейсы после 2012: все три источника
- Кейсы 2006–2012: IMF Shadow + FSI E3
- Кейсы до 2006: только IMF Shadow Economy

## 5bis. Калибровка параметров

### 5bis.1. Оценка весов $w_i$

**Метод A: PCA на пересечении (2012–2015)**

1. Собрать данные для стран с полным пересечением всех трёх источников.
2. Нормализовать каждый прокси к [0, 1].
3. Применить PCA (sklearn.decomposition.PCA).
4. Первый главный компонент — направление максимальной ковариации.
5. Веса $w_i$ = квадраты нагрузок первого компонента, нормализованные к сумме 1.

**Ожидание:** $w_{trust}$ и $w_{shadow}$ сильно коррелируют (доверие и теневая экономика — обратные индикаторы); $w_{emigration}$ — слабее. Если PCA даёт $w_{trust} + w_{shadow} \approx 0.85$, это подтверждает согласованность прокси.

**Метод B: регрессия на исторические коллапсы (обучающая выборка)**

1. Обучающая выборка: 8 кейсов из §5.2 Microfoundations_for_SDT.md.
2. Для каждого восстановить $SG_{trust}$, $SG_{shadow}$, $SG_{emigration}$ по доступным прокси.
3. Целевая переменная: $T_{факт}$.
4. Модель: $T = a + b \cdot SG_0$, где $SG_0 = w_1 \cdot SG_{trust}(0) + w_2 \cdot SG_{shadow}(0) + w_3 \cdot SG_{emigration}(0)$.
5. Оценить $w_i$, $a$, $b$ методом наименьших квадратов.
6. Проверить на тестовой выборке (§5bis.4).

### 5bis.2. Оценка $SG_{crit}$

**Метод A: точка перегиба (для кейсов с временными рядами)**

Для кейсов с годовыми рядами прокси (СССР 1985–1991, Венесуэла 2013–2020) найти точку $t^*$, где $d(SG)/dt$ максимален (инфлексия) ИЛИ начиная с $t^*$ начинается монотонный рост эмиграции / теневой экономики.

$SG_{crit}$ = средняя $SG$ в точке $t^*$ по доступным кейсам.

**Метод B: литературный порог доверия**

Из литературы (Fukuyama 1995, Putnam 2000): доверие < 30% считается критическим. При $w_{trust} \approx 0.5$: $SG_{trust} > 0.7 \Rightarrow SG_{total} > 0.35$ (нижняя граница). Для консервативности: $SG_{crit} \in [0.4, 0.6]$.

### 5bis.3. Оценка $\delta_{min}$ и $M$

**$\delta_{min}$:** из кейсов с линейным ростом (без обратной связи).

Пример (СССР, 1985–1991): $SG_0 \approx 0.5$ (средний разрыв), $SG_{crit} \approx 0.7$ (порог), $T = 6$ лет. $\delta_{min} \approx (0.7 - 0.5)/6 \approx 0.033$/год.

**$M$ (число макросостояний):** не операционализировано в §4.2.

Три варианта:
1. $M$ = число независимых каналов обратной связи (пресса, выборы, суды, гражданское общество). Измеримо по FSI / V-Dem.
2. $M$ = дисперсия в опросах (высокая дисперсия = больше различимых состояний). Измеримо по World Values Survey.
3. Отбросить $M$, работать с эмпирическим $\delta_{min}$ (вариант по умолчанию).

Рекомендация: вариант 3 для первой итерации, вариант 1 — для второй (когда есть данные).

**$\kappa$ (коэффициент мультипликативности, v3.2):** требует данных о совместном влиянии трёх компонент. До калибровки $\kappa = 1$ — консервативная нижняя оценка. Для оценки $\kappa$ нужна регрессия $T_{факт} \sim \text{imm} \times \text{elite} \times \text{fisc}$, где $\kappa$ — коэффициент при произведении. Пока данных недостаточно; задача следующей итерации.

### 5bis.4. Процедура кросс-валидации

1. **Обучающая выборка: 8 кейсов** (высокий/средний $SG_0$): Рим (Кризис III в.), Западная Римская империя, Османская империя, СССР, Венесуэла, Югославия, ГДР, Чехословакия.
2. **Тестовая выборка: 7 кейсов** (низкий $SG_0$ + несколько средних): Британская империя, Португальская империя, Австро-Венгрия, Французская монархия, Российская империя, Испанская империя, Поздняя Османская империя (1876–1908).
3. **Метрики:** MAE, Spearman rank correlation, RMSE.
4. **Baseline-сравнение:** $T_{const}$ (среднее), $T_{random}$, $T_{linear}$ ($SG_0$ без калибровки).

**Критерий успеха:** MAE(модель) < MAE(baseline) и Spearman > 0.6.

**Связь с ответом Georgescu (§6.13 Microfoundations_for_SDT.md):** если $SG$ не добавляет предсказательной силы сверх прокси по отдельности (Ответ 1), если аддитивная модель не хуже мультипликативной (Ответ 2), если эрозия институтов не коррелирует с $\gamma$ (Ответ 3) — модель отвергнута или пересмотрена.

### 5bis.5. Что нельзя калибровать в текущей версии

Честно:
- $M$ — не операционализировано.
- $\kappa$ — требует данных о совместном влиянии трёх компонент.
- Формальная связь $\delta_{min}(M)$ — не выведена.

Эти три пункта — задачи следующей итерации. Первая итерация ($w_i$, $SG_{crit}$, $\delta_{min}$ без $M$) даёт предсказание $T(SG_0)$, которое можно проверить уже сейчас.

## 6. Практические рекомендации

### Шаг 1: Скачать данные

1. **Edelman:** экспорт Excel из Dashboard
2. **IMF:** PDF → Tabula → CSV
3. **FSI:** CSV с Mendeley Data

### Шаг 2: Привести к единому формату

```python
import pandas as pd

# Edelman
edelman = pd.read_excel('edelman_trust.xlsx')
edelman = edelman.melt(id_vars=['Country'], var_name='Year', value_name='TrustIndex')

# IMF
imf = pd.read_csv('imf_shadow.csv')
imf = imf.melt(id_vars=['Country'], var_name='Year', value_name='ShadowEconomy')

# FSI
fsi = pd.read_csv('fsi_e3.csv')
fsi = fsi[['Country', 'Year', 'E3']]

# Merge
merged = edelman.merge(imf, on=['Country', 'Year'], how='outer')
merged = merged.merge(fsi, on=['Country', 'Year'], how='outer')
```

### Шаг 3: Рассчитать SG

```python
merged['SG_trust'] = 1 - merged['TrustIndex'] / 100
merged['SG_shadow'] = merged['ShadowEconomy'] / 100
merged['SG_emigration'] = merged['E3'] / 10

merged['SG_total'] = (0.4 * merged['SG_trust'].fillna(0) +
                      0.3 * merged['SG_shadow'].fillna(0) +
                      0.3 * merged['SG_emigration'].fillna(0))
```

### Шаг 4: Сохранить

```python
merged.to_csv('SG_dataset.csv', index=False)
```
